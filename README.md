# สมุดบัญชีเล่มเขียว

แอปบันทึกรายรับรายจ่ายแบบไฟล์เดียว เปิดในเบราว์เซอร์มือถือได้เลย

## ทำอะไรได้บ้าง

- บันทึกรายรับ / รายจ่าย พร้อมหมวดหมู่ วันที่ และบันทึกย่อ
- ดูยอดคงเหลือ รายรับรวม รายจ่ายรวม แยกตามเดือน
- ตั้งงบประมาณรายเดือน พร้อมเตือนเมื่อใกล้เกินและเมื่อเกินงบ
- ดูสัดส่วนรายจ่ายตามหมวดแบบกราฟแท่ง
- แตะรายการเพื่อแก้ไข หรือกด ✕ เพื่อลบ
- รองรับธีมสว่าง/มืดตามการตั้งค่าของเครื่อง

## งบประมาณ

ตั้งงบได้จากปุ่ม **ตั้งงบ** ในการ์ด "งบประมาณเดือนนี้" ค่าที่ตั้งจะผูกกับเดือนที่กำลังดูอยู่ และกลายเป็นค่าตั้งต้นของเดือนอื่นที่ยังไม่ได้ตั้งงบแยกไว้

เมื่อตั้งงบแล้ว การ์ดจะแสดง

- ยอดที่ใช้ไปเทียบกับงบ พร้อมเปอร์เซ็นต์และแถบวัด
- ขีดบอกตำแหน่งว่า ณ วันนี้ของเดือน ควรใช้ไปไม่เกินเท่าไหร่
- เงินที่เหลือ จำนวนวันที่เหลือ และยอดที่ใช้ได้ต่อวัน
- ป้ายบอกจังหวะการใช้: ประหยัดกว่าแผน / ตามแผน / ใช้เร็วกว่าแผน

สถานะของการ์ดเปลี่ยนตามสัดส่วนที่ใช้ไป — ต่ำกว่า 80% เป็นสีเขียว, 80–99% เป็นสีเหลือง, ตั้งแต่ 100% ขึ้นไปเป็นสีแดง

การเตือนจะเด้งขึ้นเฉพาะตอนที่ยอดสะสม "เพิ่งข้าม" เส้น 80% หรือ 100% เท่านั้น บันทึกรายการถัดไปหลังจากนั้นจะไม่เตือนซ้ำ

## การเก็บข้อมูล

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ไม่มีการส่งออกไปที่ไหน
ถ้าเบราว์เซอร์ไม่อนุญาตให้บันทึกถาวร แอปจะเก็บไว้ในหน่วยความจำชั่วคราวและขึ้นเตือนให้สำรองข้อมูลก่อนปิดหน้า

## สำรองข้อมูลไปโน้ต

กด **ส่งไปโน้ต** เพื่อคัดลอกข้อมูลเป็นข้อความ (หรือใช้ share sheet ของมือถือส่งเข้าแอปโน้ตโดยตรง) รูปแบบเป็นข้อความที่คนอ่านออก บรรทัดละหนึ่งรายการ:

```
# งบ ต่อเดือน | 15000.00
# งบ 2026-08 | 18000.00

2026-08-12 | จ่าย | อาหาร | 120.00 | ข้าวมันไก่
2026-08-12 | รับ | เงินเดือน | 25000.00 | -
```

บรรทัดที่ขึ้นต้นด้วย `# งบ` เก็บงบประมาณไว้ด้วย จะได้กู้คืนมาพร้อมกันในครั้งเดียว

กด **วางกลับ** แล้ววางข้อความเดิมลงไปเพื่อกู้คืน รายการที่ซ้ำกันอยู่แล้วจะไม่ถูกเพิ่มซ้ำ

# บันไดภาษี

เครื่องคำนวณภาษีเงินได้บุคคลธรรมดาแบบขั้นบันได อยู่ที่ `tax/index.html` คิดในเครื่องผู้ใช้ทั้งหมด ไม่มีการส่งข้อมูลรายได้ออกไปที่ไหน

## ทำอะไรได้บ้าง

- กรอกเงินเดือน โบนัส และรายได้ฟรีแลนซ์ แล้วเห็นภาษีทั้งปีทันทีที่พิมพ์
- ค่าลดหย่อนที่ใช้บ่อย: คู่สมรส บุตร บิดามารดา ประกันสังคม ประกันชีวิต ประกันสุขภาพ กองทุนเกษียณ ดอกเบี้ยบ้าน และเงินบริจาค
- บังคับเพดานของแต่ละรายการให้อัตโนมัติ กรอกเกินก็คิดให้เท่าที่กฎหมายให้หัก
- แสดงที่มาของตัวเลขทีละบรรทัด ตั้งแต่เงินได้จนถึงเงินได้สุทธิ
- แจกแจงว่าภาษีแต่ละบาทมาจากขั้นไหน พร้อมชี้ว่าตอนนี้อยู่ขั้นอะไร
- บอกว่าถ้าหาค่าลดหย่อนเพิ่มอีก 10,000 บาท จะประหยัดภาษีได้เท่าไหร่

## ตรรกะที่ใส่ใจเป็นพิเศษ

- **ค่าใช้จ่าย** เงินได้ประเภทที่ 1 และ 2 หัก 50% รวมกันไม่เกิน 100,000 บาท
- **ประกันชีวิตกับประกันสุขภาพ** ใช้เพดานร่วมกัน 100,000 บาท โดยประกันสุขภาพเองไม่เกิน 25,000 บาท
- **เงินบริจาค** หักหลังสุด เพดาน 10% ของเงินได้หลังหักค่าใช้จ่ายและค่าลดหย่อนอื่นแล้ว บริจาคเพื่อการศึกษาหักได้ 2 เท่าแต่ยังอยู่ใต้เพดานเดียวกัน
- **ภาษีขั้นต่ำ 0.5%** ถ้าเงินได้ที่ไม่ใช่เงินเดือนเกิน 1,000,000 บาท ภาษีต้องไม่ต่ำกว่า 0.5% ของเงินได้ส่วนนั้น แอปจะเลือกยอดที่สูงกว่าและอธิบายให้ทราบ

## อัตราภาษี

ตารางขั้นบันไดอยู่ในตัวแปร `BRACKETS` ที่ต้นสคริปต์ แก้ที่เดียวเมื่อกฎหมายเปลี่ยน

## คำถามที่พบบ่อย

ใต้เครื่องคำนวณมีส่วนคำถามที่พบบ่อย 7 ข้อ เขียนจากคำที่คนค้นหาจริง ครอบคลุมเกณฑ์ที่ต้องเสียภาษี ความเข้าใจผิดเรื่องขั้นบันได เกณฑ์ที่ต้องยื่นแบบ รายการลดหย่อน กำหนดเวลายื่น ความต่างระหว่างภาษีทั้งปีกับภาษีหัก ณ ที่จ่าย และการเลือกยื่นรวมหรือแยกของคู่สมรส

คำตอบอยู่ใน `<details>` ที่ยุบไว้เพื่อไม่ให้หน้ายาวเกินบนมือถือ แต่ข้อความอยู่ใน DOM ตั้งแต่แรกจึงถูกจัดทำดัชนีได้ตามปกติ และมี JSON-LD แบบ FAQPage กำกับ โดยชื่อคำถามใน structured data ตรงกับหัวข้อที่แสดงบนหน้าเป๊ะ ซึ่งมีเทสคุมไว้

## ยังไม่ครอบคลุม

เงินได้ประเภทที่ 3–8, ค่าลดหย่อนกระตุ้นเศรษฐกิจที่เปลี่ยนทุกปี, การเลือกยื่นรวมหรือแยกของคู่สมรส และภาษีหัก ณ ที่จ่ายระหว่างปี

ผลลัพธ์เป็นการประมาณการเพื่อวางแผน ไม่ใช่คำแนะนำทางภาษี
